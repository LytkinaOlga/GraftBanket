# Инструкция: деплой сайта + покупка домена на hoster.by

Два независимых шага: сначала выкладываем сайт на бесплатный хостинг (Vercel), потом покупаем домен на hoster.by и подключаем его к уже работающему сайту. Порядок именно такой — легче привязать готовый домен к готовому сайту, чем наоборот.

Регистрацию аккаунтов и оплату должна проводить ты сама (это твои личные данные и платёжные средства) — здесь только точная последовательность действий.

## Шаг 1. Деплой сайта на Vercel (бесплатно)

1. Зарегистрироваться на [vercel.com](https://vercel.com) (можно через GitHub-аккаунт).
2. Загрузить папку `site/` в новый репозиторий на GitHub — либо через веб-интерфейс GitHub, либо через Vercel CLI (`npm i -g vercel`, затем `vercel` из папки `site/` — можно и без GitHub).
3. В Vercel создать новый проект из этого репозитория/папки. Важно: корнем проекта должна быть именно папка `site/` (не вся `DraftBanket`).
4. В Project Settings → Environment Variables добавить две переменные (значения — в `site/.env.local`):
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_ADMIN_CHAT_ID`
5. Задеплоить. Vercel выдаст рабочий адрес вида `draft-banket.vercel.app`.
6. Проверить: открыть этот адрес, пройти заказ до конца, убедиться, что заявка пришла в Telegram.

Подробности и альтернативные варианты (локальный тест через `vercel dev`) — в `site/README.md`.

## Шаг 2. Покупка домена на hoster.by

1. Зайти на [hoster.by](https://hoster.by), зарегистрировать аккаунт (кнопка «Войти» → «Зарегистрируйтесь»).
2. В поиске домена на главной странице ввести желаемое имя (например, `draftbanket`) и нажать «Подобрать».
3. Выбрать зону. Ориентировочные цены на момент написания (за первый год):
   - `.by` — 42.50 BYN (при покупке `.by` в подарок дают `.site`, `.xyz`, `.online`)
   - `.бел` — 32.00 BYN (сейчас со скидкой)
   - `.com` — 77.00 BYN
   - `.site` — 11.00 BYN (первый год, дальше дороже)
   - Для бизнеса, работающего в Беларуси, обычно логичнее `.by` или `.бел` — привычнее клиентам и лучше для локального SEO.
4. **Важный нюанс зон `.by` и `.бел`**: по правилам белорусского регулятора для регистрации нужно указать паспортные данные (если регистрируешь как физлицо) или УНП компании (если как ИП/юрлицо). Для международных зон (`.com`, `.site`, `.online` и т.п.) этого не требуется — только обычные контактные данные.
5. Добавить домен в корзину, оформить и оплатить (карта, ЕРИП, Apple Pay — способы оплаты видно на этапе оформления).

## Шаг 3. Подключить домен к Vercel

После того как сайт задеплоен (шаг 1) и домен куплен (шаг 2):

1. В Vercel: Project → Settings → Domains → добавить свой домен (например, `draftbanket.by`).
2. Vercel покажет DNS-записи, которые нужно добавить — обычно A-запись для корневого домена и CNAME для `www`. Точные значения показывает сам Vercel в момент добавления домена (они у Vercel периодически меняются, поэтому важно скопировать именно те, что показаны тебе, а не старые примеры из интернета).
3. Зайти в личный кабинет hoster.by → раздел с доменами → выбрать домен → DNS-редактор.
4. Добавить/изменить записи в точности так, как указал Vercel (обычно: A-запись `@` → IP-адрес Vercel; CNAME `www` → адрес вида `cname.vercel-dns.com`).
5. Сохранить. DNS-изменения расходятся по интернету от нескольких минут до 24–48 часов (обычно быстрее).
6. Вернуться в Vercel — как только он увидит правильные DNS-записи, домен подтвердится и автоматически выпустится бесплатный SSL-сертификат (https).
7. Открыть сайт по новому домену, ещё раз пройти заказ до конца и проверить Telegram.

## Если домен и хостинг нужно держать у одного провайдера

Если вместо Vercel захочешь разместить сайт прямо на хостинге hoster.by — учти, что там нужен хостинг с поддержкой Node.js serverless-функций (для `api/order.js`) либо переписать отправку в Telegram под их окружение (например, обычный PHP-хостинг потребует переписать `api/order.js` на PHP). Это отдельная задача — дай знать, если решишь пойти этим путём, помогу адаптировать код.
