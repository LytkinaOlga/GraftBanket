# Что реализовать до утверждения точного ассортимента

Обновлено: 12 сентября 2026. Этот список отделяет работу, которая не зависит от состава и цен боксов, от наполнения каталога. Публичный сайт пока содержит заглушки и не готов к рекламе.

## 1. Основа каталога

- Ввести два типа товара: `box` (готовый бокс) и `snack` (позиция конструктора). Отображать сначала готовые боксы, затем конструктор; сохранять возможность положить оба типа в одну корзину.
- Для каждого товара хранить `id`, название, описание, фото, цену, статус доступности. Для закуски добавить `minQty` и `qtyStep`, для бокса — фиксированную комплектацию и количество боксов.
- Не добавлять в публичный каталог позиции с неполными данными. Пока нет утверждённых боксов, использовать только тестовые данные в закрытом просмотре.
- В конструкторе первое нажатие «Добавить» ставит `minQty`, «+» прибавляет `qtyStep`, «−» вычитает `qtyStep` и удаляет товар при переходе ниже минимума. Проверять правила при восстановлении корзины и на сервере.

## 2. Корзина и доставка

- Корзина допускает совместный заказ боксов и закусок. Отдельно показывать стоимость товаров, доставку и предварительный итог.
- Способ получения: самовывоз; доставка в пределах МКАД; доставка за пределы МКАД/другое место — «стоимость уточнит администратор».
- Для доставки в пределах МКАД: 20 BYN при стоимости товаров ниже 500 BYN, 0 BYN от 500 BYN. До уточнения считать порог по стоимости товаров без доставки и без скидок; скидки в текущей версии не вводить.
- Для самовывоза доставка 0 BYN. Для внешней зоны не показывать придуманный итог с доставкой: обозначить, что стоимость будет согласована.

## 3. Заявка

- Поля: имя, телефон, желаемая дата и время, способ получения, адрес/район для доставки, комментарий, необязательный ник Telegram.
- Форму отправлять как заявку; на экране успеха писать, что администратор свяжется для подтверждения доступности, итоговой стоимости и условий.
- Сохранить корзину и введённые данные при сетевой ошибке. Исключить случайные повторные отправки с одной кнопки.
- Передавать в Telegram номер заявки, контактные данные, дату/время, способ получения, товары, стоимость товаров, предварительную доставку и источник перехода.
- Дату и время пока не ограничивать неутверждённым сроком предзаказа; проверять корректность формата и будущую дату. После решения владельца добавить точные ограничения.

## 4. Сервер и безопасность

- Сервер принимает только `id` и количества товаров, сам берёт актуальные названия и цены из каталога, сверяет минимум и шаг, пересчитывает стоимость товаров и доставку.
- Хранить токен Telegram только в переменных окружения. Перевыпустить токен, опубликованный в README, и удалить его из инструкции.
- Добавить защиту от бессмысленных и повторных запросов, ограничение размера заявки и аккуратные сообщения об ошибках без выдачи внутренних данных клиенту.
- Хранить уникальный номер заявки и иметь способ проверить, доставлено ли уведомление администратору. Для рабочего запуска нужен резервный учёт заявок, чтобы сбой Telegram не означал потерю контакта.

## 5. Страница и проверка

- Перестроить первый экран вокруг выбора: «Готовые боксы» и «Собрать свой набор». Добавить блок условий получения и объяснение, что заказ подтверждает администратор.
- Подготовить адаптивный вид на телефоне, понятные состояния пустого каталога, корзины и ошибок.
- Провести сквозные проверки: бокс + закуски в одной корзине; минимум и шаг; доставка 499,99/500 BYN; самовывоз; внешняя зона; ошибка Telegram; повторное открытие страницы с сохранённой корзиной.

## Данные, которые нужны позднее для публикации

- Утверждённые боксы: название, точный состав и количество, цена, фото, срок предзаказа.
- Закуски конструктора: название, состав, цена, минимум, шаг, фото.
- Адрес и часы самовывоза, интервалы доставки, точный срок предзаказа, предоплата, правила изменения и отмены.
- Публичные контакты, название направления, домен и оформление Instagram.

4. После получения данных заменить тестовый каталог реальным и провести фотопроверку.
