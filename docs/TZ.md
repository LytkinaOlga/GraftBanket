# Техническое задание

## Сайт-витрина для сервиса банкетного кейтеринга «Draft Catering»

Версия 1.0 · 11 июля 2026

---

## 1. Общее описание проекта

Draft Catering — сервис изготовления еды на банкеты. Требуется сайт-витрина (без регистрации и без онлайн-оплаты на данном этапе), где посетитель может:

- ознакомиться с полным перечнем блюд по категориям — фото, вес, цена за единицу, состав, описание;
- сформировать корзину из нужных позиций;
- отправить корзину как заявку, указав ник в Telegram и номер телефона;
- заявка автоматически приходит администратору в отдельный Telegram-бот.

Сайт адаптируется преимущественно под мобильные устройства (mobile-first), с корректным отображением и на десктопе.

## 2. Структура и функционал сайта

### 2.1 Шапка (Header)

- Название «Draft Catering» (логотип — заглушка, до предоставления реального лого).
- Контактный номер телефона (заглушка на старте, реальный номер подставляется позже).
- Иконка корзины со счётчиком количества позиций, доступная с любой страницы/экрана.

### 2.2 Каталог блюд

Каталог разбит на категории. Итоговый список категорий:

| № | Категория |
|---|---|
| 1 | Брускетты |
| 2 | Профитроли |
| 3 | Рулетики |
| 4 | Тарталетки |
| 5 | Мини сэндвичи |
| 6 | Салаты |
| 7 | Мини бургеры |
| 8 | Киши |
| 9 | Чизкейки |
| 10 | Рулеты бисквитные |
| 11 | **Сеты** |
| | — Сыры и фрукты |
| | — Мясные нарезки |
| | — Фритюрный сет |
| | — Сет под крепкие напитки |

Внутри каждой категории — несколько позиций (карточек блюд). На старте количество и содержание позиций — сгенерированные заглушки; реальные данные (фото, вес, цена, состав, описание) владелец добавит позже через тот же формат данных.

### 2.3 Карточка блюда

Каждая карточка содержит:

- фотографию (заглушка на старте);
- название блюда;
- вес / объём порции;
- цену за единицу;
- состав;
- описание;
- кнопку «Добавить» — добавляет позицию в корзину (при повторном нажатии увеличивает количество).

### 2.4 Корзина

- Доступна через иконку в шапке / плавающую кнопку — переход в один тап.
- Отображает список добавленных позиций: название, фото, цена за единицу, количество, сумма по позиции.
- Позволяет менять количество (+ / −) и удалять позицию.
- Показывает итоговую сумму заказа.
- Кнопка «Оформить заявку» ведёт к форме контактных данных.

### 2.5 Оформление заявки

- Поле «Ник в Telegram» (обязательное).
- Поле «Номер телефона» (обязательное, с базовой валидацией формата).
- Кнопка «Отправить заявку».
- После отправки — экран подтверждения («Заявка отправлена, мы скоро с вами свяжемся») и корзина очищается.

### 2.6 Сохранение состояния корзины

Регистрация не требуется. Корзина сохраняется в браузере пользователя (локальное хранилище устройства), поэтому при случайном закрытии и повторном открытии вкладки/сайта содержимое корзины восстанавливается автоматически. Хранение ограничено сроком (например, 48 часов) и очищается после успешной отправки заявки.

## 3. Интеграция с Telegram

- **Бот администратора** — отдельный Telegram-бот, создаваемый через @BotFather.
- **Приём заявок** — при отправке формы сервер сайта обращается к Telegram Bot API и присылает администратору сообщение с полным составом заявки.
- **Содержание сообщения боту** — дата и время заявки; ник в Telegram и телефон клиента; список позиций (название, кол-во, цена за ед., сумма по позиции); итоговая сумма заказа.
- **Безопасность** — токен бота хранится на сервере (серверная функция), а не в коде сайта, видимом пользователю.

## 4. Технические решения

### 4.1 Фронтенд

- Адаптивная вёрстка, приоритет — мобильный экран (mobile-first), поддержка десктопа.
- Дизайн уточняется по референсам, которые предоставит заказчик.

### 4.2 Бэкенд / интеграция с ботом

- Небольшая серверная функция, принимающая данные заявки и пересылающая их в Telegram Bot API.
- Данные о блюдах хранятся в структурированном виде (легко редактируются и заменяются на реальные).

### 4.3 Хостинг и домен

На момент составления ТЗ домен и хостинг ещё не выбраны. План:

- этап разработки и демонстрации — бесплатный хостинг с временным адресом;
- после согласования сайта — подключение постоянного домена и хостинга, когда они будут приобретены.

## 5. Контент на старте

Готовы только названия категорий. Все конкретные позиции блюд, фото, вес, цены, состав и описания — временные заглушки со сгенерированными данными. Реальный контент владелец добавит позже, структура сайта это позволяет без переделки.

## 6. Что не входит в текущую версию

- онлайн-оплата на сайте;
- регистрация и личный кабинет пользователя;
- админ-панель для редактирования меню (изменения вносятся через файл данных);
- интеграции с CRM, аналитикой и т.п.

Эти пункты можно добавить отдельным этапом при необходимости.

## 7. Этапы работ

1. Согласование ТЗ и референсов дизайна — текущий этап.
2. Создание Telegram-бота (по инструкции).
3. Вёрстка сайта: каталог, карточки блюд, корзина, форма заявки — с заглушками.
4. Подключение сохранения корзины и отправки заявки в бот.
5. Тестирование на мобильных устройствах.
6. Публикация на временном хостинге для проверки.
7. Подключение домена и постоянного хостинга (когда будут готовы).
8. Замена заглушек на реальные фото/тексты/цены.
