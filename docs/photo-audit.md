## Для окончательных карточек

По каждому утверждённому боксу нужны: публичное название, точный состав, количество каждого вида и общий вес, цена, фото-обложка, срок предзаказа, ориентир по гостям, возможность замены. Для каждого товара конструктора: точное название, состав/аллергены, единица и цена, минимум, шаг заказа, фото.
